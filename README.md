# TSC Registration Form — online preview

Single-file, browser-only registration form for the Master's Toronto Satsang Program.
Nothing is sent to or stored on any server; drafts live in the visitor's own browser.

- `index.html` — the form (published via GitHub Pages)
- Source of truth lives in `registration-form/Dynamic/registration.html` on the maintainer's PC; this repo only holds the published copy.
